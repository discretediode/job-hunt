# Setup Profile
Run the initial onboarding process to configure the job-hunting agent.

## Instructions
1. Check if a CV is available in `documents/cv/` or provided by the user.
2. If a CV is available, run `python3 setup.py --magic <path_to_cv>`.
3. Otherwise, run `python3 setup.py` for interactive setup.
4. Inform the user once the profile is configured and mention if there are any remaining gaps in `my_profile/`.
