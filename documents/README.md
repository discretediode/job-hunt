# documents/

Career documents used as attachments and as source material for application forms:
transcripts, enrolment certificates, diplomas, reference letters.

    documents/
    ├── diplomas/      school-leaving and language qualifications
    ├── references/    reference letters from past employers
    ├── cv/            any externally-authored CV versions
    └── postings/      saved job adverts

Contents are gitignored - only this README is tracked. These are personal documents
and never belong in a remote repository.
