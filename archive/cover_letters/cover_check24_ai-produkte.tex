\lettercontent{Mein stärkstes Argument für diese Rolle ist ein konkretes Projekt: Ich habe einen AI Application Generator in Python gebaut, der über die Google Gemini API Bewerbungsunterlagen vollständig automatisiert generiert. Das System umfasst eine sichere Datenpipeline mit PII-Stripping und Re-Injektion, Prompt-Engineering für konsistente LLM-Outputs und automatisierte PDF-Erzeugung. Als Entwicklungsumgebung nutzte ich Claude Code, ein agentenbasiertes Coding-Tool. Ergänzend dazu habe ich im Rahmen meines Forschungsassistentenjobs an der HM München Python-Skripte zur Auswertung von SFRA-Messdaten entwickelt und die Ergebnisse für ein gemischtes Fachpublikum dokumentiert. Meine drei stärksten Beiträge auf einen Blick:}
